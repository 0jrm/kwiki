**Entity + edge schema (authoritative):**

```jsonl
# _graph/entities.jsonl — one JSON object per line
{"id": "person:sarah-chen", "type": "person", "name": "Sarah Chen", "attributes": {"role": "engineer"}, "sources": ["journal/2026-04-12.md"], "first_seen": "2026-04-12T10:00:00Z", "last_seen": "2026-04-15T14:22:00Z"}
{"id": "library:rank-bm25", "type": "library", "name": "rank_bm25", "attributes": {"lang": "python"}, "sources": ["concepts/bm25.md"], "first_seen": "2026-04-10T09:00:00Z", "last_seen": "2026-04-10T09:00:00Z"}

# _graph/edges.jsonl — one JSON object per line
{"src_id": "project:kwiki", "dst_id": "library:rank-bm25", "type": "uses", "confidence": 0.8, "sources": ["projects/kwiki.md"], "first_seen": "2026-04-10T09:00:00Z", "last_seen": "2026-04-10T09:00:00Z"}
```

**Entity types (fixed vocabulary — start small):** `person`, `project`, `library`, `concept`, `file`, `decision`.

**Edge types (fixed vocabulary):** `uses`, `depends_on`, `contradicts`, `caused`, `fixed`, `supersedes`, `mentions`, `owned_by`, `related_to`.

**Deduplication rule:** Entities are deduped by `(type, normalized_name)`. Normalization: lowercase, strip punctuation, collapse whitespace, dash-join. ID format: `{type}:{normalized_name}` (e.g. `"person:sarah-chen"`, `"library:rank-bm25"`). On duplicate detection, merge `sources` (union), update `last_seen`, keep `first_seen` from the existing entry.

**Edge confidence:** Follows PR #1 rules — more independent sources = higher confidence. Default `0.6` for edges observed in one source, `0.8` for two, `0.9` for three or more. Capped at `1.0`.
