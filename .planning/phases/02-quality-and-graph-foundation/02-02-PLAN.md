**Backward compat constraint (NON-NEGOTIABLE):** Vaults with pages that lack `quality:` must still work. Lint computes a quality score at lint time for any page missing the field. Write-paths (wiki-ingest, wiki-update) only set `quality:` on pages they are actively creating or updating — no retroactive backfill on pages the user hasn't touched.

**Quality score heuristic (authoritative):**

Score is a float in `[0.0, 1.0]`, computed from weighted signals. All signals are read from frontmatter or body — no external lookups.

| Signal                          | Weight | Score contribution                                                |
|---------------------------------|--------|-------------------------------------------------------------------|
| `confidence` present + ≥ 0.7   | 0.25   | full; half if present & < 0.7; 0 if absent                        |
| `sources_count` ≥ 2             | 0.15   | full; half if = 1; 0 if absent/0                                  |
| `summary:` frontmatter present  | 0.10   | full if ≥ 20 chars; 0 otherwise                                   |
| Wikilink count ≥ 3              | 0.20   | full; half if 1–2; 0 if none                                      |
| `entities:` count ≥ 2           | 0.15   | full; half if = 1; 0 if absent/empty                              |
| Body length ≥ 200 chars         | 0.10   | full; half if 50–199; 0 if < 50                                   |
| `last_confirmed` within 90 days | 0.05   | full; 0 otherwise                                                 |

Sum of all seven contributions = final quality score, rounded to 2 decimals. Pages scoring < 0.4 are flagged "low quality" in lint output (no auto-fix — quality is a signal, not a blocker).

**Self-healing lint actions (auto-fix by default):**
- **Orphans** (no incoming wikilinks): invoke cross-linker with `--use-graph` to add incoming links where entity/title matches exist. If no natural match is found, skip the page (don't force-link).
- **Broken wikilinks** (target page doesn't exist): three resolution strategies, tried in order — (1) fuzzy match to an existing page title within same category, (2) match via `_graph/entities.jsonl` alias, (3) if both fail, rewrite the broken `[[link]]` to plain text and log the removal (don't leave a dead link rotting in the page).
- **Missing frontmatter** (the existing check): unchanged — still reported, not auto-fixed (schema completions are too lossy to auto-generate).

`--report-only` flag preserves the pre-PR-#8 behavior (list issues, make no changes). Auto-fix is the default.

2. **Modify `### 1. Orphaned Pages`:** Change the section so it describes both behaviors:

```markdown
### 1. Orphaned Pages

An orphan is a page with no incoming `[[wikilinks]]` from any other page.

**Self-healing (default):**
1. Invoke `cross-linker --use-graph` restricted to this orphan as the target.
2. cross-linker scans all pages for natural mentions of the orphan's title or aliases, and adds links where matches exist.
3. If no natural match is found, skip the page and keep it listed as orphan in the report (don't force-link — a forced link is worse than an orphan).

**Report-only mode:** list the orphan; take no action.
```

3. **Modify `### 2. Broken Wikilinks`:**

```markdown
### 2. Broken Wikilinks

A broken wikilink points to a page that doesn't exist.

**Self-healing (default):** try three strategies in order.

1. **Fuzzy match within category** — if the link reads `[[BM25 Scoring]]` inside a `concepts/` page, look for the closest title match in `concepts/*.md` (Levenshtein distance ≤ 3 or matching bag-of-words). Rewrite the link to the matched page.
2. **Graph alias match** — check `_graph/entities.jsonl` for an entity whose `name` or aliases matches the broken link text. If found, rewrite the link to the entity's primary page (same resolution as cross-linker Step 2.5).
3. **Strip to plain text** — if both fail, rewrite `[[broken-link]]` to `broken-link` (plain text) and log the rewrite. A dead `[[link]]` is noise; plain text is honest.

**Report-only mode:** list the broken link and which of the three strategies would apply; change nothing.
```

4. **Modify `### 3. Missing Frontmatter`:** Add a note: "Always reported, never auto-fixed — schema completions are too lossy to generate automatically."
