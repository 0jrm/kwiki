**Audit log format:**
File: `$OBSIDIAN_VAULT_PATH/_meta/audit.jsonl`
Append-only — one JSON object per line, never delete or rewrite existing lines.
Created automatically on first write (mkdir -p _meta/ if needed).

**Entry schema:**
```json
{
  "ts": "2026-04-15T10:30:00.000Z",
  "op": "ingest",
  "skill": "wiki-ingest",
  "page": "concepts/ml-fundamentals.md",
  "source": "papers/attention-is-all-you-need.pdf",
  "action": "create",
  "session": null
}
```

Fields:
- `ts`: ISO 8601 with milliseconds. Use current wall-clock time.
- `op`: operation category. Values: `ingest` | `update` | `lint-fix` | `rebuild` | `link` | `tag` | `delete`
- `skill`: the skill that wrote the entry. String, e.g. `"wiki-ingest"`, `"wiki-update"`, `"data-ingest"`, `"wiki-lint"`, `"cross-linker"`, `"tag-taxonomy"`, `"wiki-rebuild"`
- `page`: vault-relative path of the page modified. `null` if no specific page (e.g. bulk rebuild start).
- `source`: vault-external path or identifier of the source. `null` if n/a (e.g. lint-fix has no external source).
- `action`: specific change type. Values: `create` | `update` | `delete` | `link` | `fix` | `tag`
- `session`: optional session identifier (null if not tracking sessions)

**Append pattern (shell):**
```bash
echo '{"ts":"...","op":"ingest","skill":"wiki-ingest","page":"concepts/foo.md","source":"path/to/source","action":"create","session":null}' >> "$OBSIDIAN_VAULT_PATH/_meta/audit.jsonl"
```

Or via Write tool: read current audit.jsonl, append new line, write back. Never overwrite — only append.
