**Backward compat constraint (NON-NEGOTIABLE):** If `_graph/entities.jsonl` or `_graph/edges.jsonl` does not exist, `wiki-query` must still answer from existing non-graph flow with no hard failure.

**Traversal model (authoritative for this PR):**
- Seed set: top lexical/entity matches for the query.
- Walk depth: default 1 hop, optional 2 hops with explicit user request (`deep`, `expand graph`).
- Edge weighting by type:
  - `depends_on`, `uses`, `fixed`: 1.0
  - `related_to`, `mentions`, `owned_by`: 0.7
  - `supersedes`: 0.8 (forward-only preferred)
  - `contradicts`: 0.6 (include with caution label)
- Per-hop decay: multiply score by 0.75 each hop.

**Safety rule:** Graph expansion should add candidate context, not replace direct query matches.
