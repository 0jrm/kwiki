**Fusion rule (authoritative):**
Use Reciprocal Rank Fusion:
`RRF(d) = Σ_i 1 / (k + rank_i(d))`
with default `k = 60`.

Streams:
1. BM25 lexical ranking (always available)
2. Graph traversal ranking (from PR #6)
3. Vector ranking (optional; only when `QMD_WIKI_COLLECTION` is set and query succeeds)

**Fallback constraints:**
- If vector backend is unavailable/unset, run 2-stream fusion (BM25 + graph) with no failure.
- If graph files are missing, run BM25-only (or BM25 + vector if configured).
- Any single-stream failure degrades gracefully; never abort the whole query.
</context>
